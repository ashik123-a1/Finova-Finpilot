1. Purpose, Scope and Status Labels
This document defines functional requirements, security boundaries, data rules, API integration expectations, acceptance tests,
and staged delivery for SME Finance Copilot. It is the baseline for frontend development, testing, architecture documentation,
and the competition demo.
 Label
Meaning
Core / Competition MVP
Must work end-to-end in the demo.
Reported implemented
Mentioned in previous agent reports; verify against actual code and runtime.
Demo / simulated
Uses synthetic data or simulated actions and must be labelled.
Integration-dependent
Requires approved provider, credentials, permissions and testing.
Advanced / roadmap
Agreed product direction, not a promise of current completion.
Open decision
Needs measured configuration; do not invent a value.
Product vision
One unified AI Business Manager that helps SMEs understand performance, manage cash flow, compare financing options,
manage customers/inventory, process voice/photo inputs, simulate business decisions, and automate routine tasks. It combines
deterministic calculations, explainable rules, suitable ML/statistical forecasts, and an AI interface constrained by permissions
and evidence.
Principles

 Financial analysis, cash-flow management with alerts, and financing-option matching are the three highest-priority competition
tasks.

 Use deterministic code for financial arithmetic and loan rules; use an LLM for dialogue, summaries, explanations and
approved tool orchestration.

 Never present synthetic bank offers, simulated message delivery, forecasts or estimates as verified real-world facts.

 Human review is required before uncertain extraction or consequential financial writes are committed.

 Keep the service free to end users as a product requirement, while managing hosting/provider costs with sustainable
local/free/demo alternatives.
